# Content QA Playbook

Практические чек-листы и шаблоны для проверки контента и интерфейсов на сайте и в мобильном приложении. Собрано из реальных релизных проверок веб-продукта: наполнение страниц, публикация через CMS, сверка справочников, адаптив, DevTools, отчёты о дефектах.

**Зачем:** контент ломается не в редакторе, а после публикации — в другом браузере, на другой ширине экрана, в приложении с кэшем. Чек-листы помогают проверять одинаково и не пропускать дорогие ошибки (цены, сроки акций, условия тарифов).

## Принципы

1. **Сверять с источником**, а не с прошлой версией страницы: цифры, сроки акций, названия, единицы.
2. **Проверять после публикации**, а не только в редакторе: кэш, CDN, приложение.
3. **Фиксировать доказательства**: скриншот, URL, версия приложения, шаги воспроизведения.
4. **Ошибка в цене или условиях — критично**: сообщать сразу, не дожидаясь плановой проверки.
5. **После исправления — перепроверить** и соседние страницы, использующие тот же шаблон.
