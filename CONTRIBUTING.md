# Contributing

Спасибо, что заглянули. Репозиторий собирает практические чек-листы и шаблоны проверки контента. Формат простой: один файл, одна задача, никакой воды.

## Что можно добавить

- Новый чек-лист для конкретного сценария: публикация, мобильное приложение, сверка справочников, локальная версия сайта.
- Шаблон: баг-репорт, задача на правку, релизный чек-лист.
- Пример заполнения: как выглядит готовый отчёт или задача.
- Улучшение формулировок: короче, конкретнее, без жаргона.

## Правила

1. Текст на русском или английском, коротко и по делу. Английские версии ключевых файлов приветствуются.
2. Каждый пункт должен быть проверяемым: что смотреть, где смотреть, что считать ошибкой.
3. Не добавлять персональные данные, названия компаний и внутренние ссылки.
4. Один PR, одна тема. Описание PR: что добавлено и зачем.
5. Новые файлы добавлять в README в таблицу.

## Как проверить перед PR

- Файл открывается, markdown не сломан.
- Ссылки в README ведут на существующие файлы.
- Нет длинных тире, лишних пробелов и дублей.

## Лицензия

Добавляя файлы, вы соглашаетесь с лицензией MIT.
