# Чек-лист: контент в мобильном приложении

- [ ] Текст и цены совпадают с сайтом и справочником.
- [ ] Длинные названия не обрезаются и не ломают вёрстку.
- [ ] Проверено на реальном устройстве и на эмуляторе.
- [ ] Проверено на разных версиях ОС и размерах экрана.
- [ ] Кэш очищен и приложение перезапущено - данные обновились.
- [ ] Плохая сеть: контент не пропадает, есть состояние загрузки/ошибки.
- [ ] Скриншоты и версия приложения приложены к отчёту.
- [ ] Если контент приходит с API - проверен ответ (200, структура, кодировка).
- [ ] После исправления выполнена повторная проверка на том же устройстве.
