# Чек-лист: страница сайта

## До публикации

- [ ] Текст сверен с источником: цифры, сроки, названия, единицы измерения.
- [ ] Цены и условия акций совпадают с утверждённым справочником.
- [ ] Ссылки ведут на существующие страницы, без редиректов на 404.
- [ ] Изображения загружены, есть alt-текст, пропорции не искажены.
- [ ] Заголовки и подзаголовки в правильной иерархии (h1 → h2 → h3).
- [ ] Нет опечаток, двойных пробелов, «ё»-разнобоя, рваных переносов.
- [ ] Дата публикации и срок действия акции указаны и корректны.

## После публикации

- [ ] Страница открывается по прямому URL, HTTP 200.
- [ ] Контент виден без авторизации (если страница публичная).
- [ ] На 320, 390, 768, 1024, 1440, 1920 px нет обрезки, наложений и горизонтального скролла.
- [ ] В консоли нет ошибок; в Network нет 404 по ресурсам страницы.
- [ ] Кнопки и ссылки работают, ведут туда, куда заявлено.
- [ ] Соседние страницы того же шаблона не сломались.
- [ ] В мобильном приложении (если контент общий) отображается тот же текст и цены.
- [ ] При повторном входе и с очищенным кэшем показывается новая версия.

## Приёмка

- [ ] Скриншот «до/после» сохранён.
- [ ] URL, дата и браузер зафиксированы в задаче.
- [ ] Если правили шаблон — проверены все страницы на нём.
