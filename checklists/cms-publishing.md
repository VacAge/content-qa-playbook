# Чек-лист: публикация через CMS

- [ ] Выбрана правильная коллекция/раздел и язык (ru/en).
- [ ] Заполнены обязательные поля; необязательные — по задаче.
- [ ] Заголовок и описание не превышают лимиты шаблона.
- [ ] Медиа загружено в библиотеку, указан alt-текст, размер оптимизирован.
- [ ] Предпросмотр совпадает с ожидаемым результатом.
- [ ] Ссылки в тексте проверены до сохранения.
- [ ] Понятно, что публикуется: черновик не уходит в прод случайно.
- [ ] После публикации проверен публичный URL (кэш сброшен).
- [ ] История версий показывает новую запись; откат возможен.
- [ ] В задаче отмечено: что изменено, где, кто проверил.
