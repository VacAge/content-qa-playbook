# Чек-лист: справочники и каталоги

- [ ] Сверка построчно с эталоном (выгрузка, биллинг, утверждённая таблица).
- [ ] Нет пропавших записей: количество строк совпадает с эталоном.
- [ ] Нет дублей по ключу (ID, код услуги, slug).
- [ ] Цены совпадают во всех каналах: сайт, приложение, карточка, корзина.
- [ ] Сроки акций не истекли; архивные позиции помечены.
- [ ] Единицы измерения и валюта одинаковые.
- [ ] Сортировка и фильтры работают на новых данных.
- [ ] Граничные случаи: минимальная/максимальная цена, опции, скидки.
- [ ] После импорта проверены 5–10 случайных записей вручную.
- [ ] Расхождения зафиксированы и не опубликованы до подтверждения.
