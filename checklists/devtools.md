# Чек-лист: браузерные инструменты разработчика

- **Console**: нет красных ошибок; предупреждения оценены (сторонние библиотеки - не блокер).
- **Network**: все ресурсы 200; нет 404/500; размеры изображений разумные; кэш-заголовки корректны.
- **Elements**: контент в нужном блоке, стили не переопределены, скрытые элементы действительно скрыты.
- **Device toolbar**: 320/390/768/1024/1440 px; поворот экрана; отсутствие горизонтального скролла.
- **Performance**: нет долгих задач из-за тяжёлых изображений/скриптов на странице контента.
- **Application**: cookie/localStorage не мешают показывать актуальную версию.
- **Проверка после публикации**: hard reload (Ctrl+Shift+R) и инкогнито.
